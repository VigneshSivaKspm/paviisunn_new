# ☀️ Pavii Sunn — Solar Power Solutions

A modern, fully responsive **React + Vite** website for **Pavii Sunn**, a leading solar energy company based in Tamil Nadu, India. Rebuilt from the ground up with a premium dark UI, smooth animations, and all original content preserved.

## ✨ Features

- **Modern Dark UI** — Premium solar-themed color palette (deep blacks + vibrant orange/amber gradients)
- **Fully Responsive** — Mobile-first design, works on all screen sizes
- **Hero Slider** — Auto-rotating full-screen slideshow with bilingual content (English + Tamil)
- **Animated Stats Counter** — Count-up animation triggered on scroll
- **Project Gallery** — Masonry grid with built-in lightbox viewer
- **Infinite Partner Ticker** — Auto-scrolling partner logos with pause on hover
- **Pricing Table** — All 10 solar plans with subsidy info
- **Contact Form** — Validated form with success state
- **Google Maps Embed** — Coimbatore office location
- **PM Surya Ghar Modal** — Government scheme details with bilingual text
- **Back to Top Button** — Fixed position with smooth scroll
- **SEO Optimized** — Meta tags, semantic HTML, proper heading hierarchy

## 🏃 Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

---

## ☁️ Deploying to Vercel

### Option 1 — Vercel CLI
```bash
npm install -g vercel
vercel --prod
```

### Option 2 — Vercel Dashboard
1. Push this folder to a GitHub repository
2. Go to [vercel.com](https://vercel.com) → **New Project**
3. Import your GitHub repo
4. Vercel auto-detects Vite — click **Deploy**
5. Done! ✅

> The `vercel.json` file handles SPA routing, image caching, and security headers automatically.
